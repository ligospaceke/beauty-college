# Covelyne Maison - static site for GitHub Pages
1. Create a GitHub repository and upload everything in this folder to the root.
2. Settings > Pages > Deploy from branch > main / (root).
3. Open https://<user>.github.io/<repo>/#/admin  (demo password: covelyne2026, change it in Settings).
4. Edit products, stock, courses, photos and orders. Choose Publish to GitHub (needs a fine-grained token with Contents read/write on this repo), or Download site.json and replace data/site.json in the repo.
Order tracking reads the Orders tab, so add an order number and status there when you take an order.
